Chat Plays — You Control the Game!

Type commands in Twitch chat and watch Pokémon LeafGreen move on stream. Everyone plays together!

ℹ️ Sometimes Chat Plays is in test mode (only a few testers can play) or takes a short break. If your commands don't do anything, that's all it is — nothing's broken, and it'll be back!

How to play

One command does it all: !p followed by the buttons you want to press. No cooldown — spam away.

Press a button

!p a

Presses the A button once. That's it — you just played! There's no waiting between commands, so send the next one whenever you like.

Hold a button — add a number of seconds

!p up 3

Holds Up for 3 seconds, so your character walks up. When nobody else is waiting you can hold for up to 7 seconds — ask for more and it just holds for 7.

Chain a few together (up to 5)

!p up 1 a b

Walks up for 1 second, then presses A, then B. Each number sticks to the button right before it. The bot re-checks the screen before every single press, so a chain is just as safe as one button.

Type it however you like

!p U D L R

Capitals are fine, and every direction has a short form. u, d, l, r are up, down, left and right — so !p l 2 a is the same as !p left 2 a.

Long holds when you're the only one playing

!p up 7

Holds depend on whether anyone is waiting behind you:

Longest single holdTotal holding per command
Queue empty — nobody waiting7 seconds10 seconds
Someone's waiting2 seconds3 seconds

So on a quiet stream you can walk right across a route with !p up 7, and when the place is busy everyone gets a quick turn instead of watching one person hold Up. Ask for a longer hold than you're allowed and it just gets shortened.

Good to know

• There's no cooldown, so you can send commands back to back.

• If lots of people are playing, commands line up in a queue and run in order. One press happens at a time, and the bot takes a fresh look at the screen before every single one.

• Your whole command runs before the next person's starts, so nobody's inputs get tangled up with yours.

• Some commands get skipped on purpose when they'd press a button at a bad moment — the bot is keeping the game safe. Just try again!

When a button gets skipped

The bot checks the screen before every press, so what happens depends on where the game is:

You'll seeWhat it means
Just one button ignoredThat button isn't safe on this screen (like a on a "Release this POKéMON?" prompt). Everything else still works — try a different button!
Everyone paused for a momentThe game landed somewhere it shouldn't be. The bot presses its own way out and hands control straight back.
Chat Plays stops completelySomething serious came up. The bot unplugs itself on the spot and waits for a human — it'll be back once the stream runner sorts it out.
"MANUAL" on the overlayThe stream runner has taken the controller for a bit. Commands come back when they hand it over.

Play mode — drop the !p

Settling in for a proper session? Turn play mode on and just type buttons.

!enterplaymode

From then on, your normal chat messages count as button commands — no !p needed. Type a and it presses A; type up 3 and it walks up. Everything else works exactly the same, limits and all.

You typeWhat happens
!enterplaymodePlay mode on — the bot confirms in chat
aPresses A
up 3 aWalks up for 3 seconds, then presses A
!pointsStill just a normal command — play mode doesn't touch it

Leaving is as easy as talking

Say two things in a row that aren't buttons — "nice one", "lol" — and play mode switches itself off, with one message telling you so. That's not a telling-off; it's just how you leave. Nothing gets deleted, nothing counts against you, and !enterplaymode puts you straight back in.

You can also type !exitplaymode whenever you want out, and play mode turns itself off after 10 minutes of not playing so it's never on when you've forgotten about it.

Two small gotchas

• While you're in play mode, a message that's only button words gets played — so a lone b in chat presses B. That's the whole point, but it surprises people once.

• Play mode is per-person. Being in it doesn't stop anyone else playing, and everyone's commands still share the same queue.

The rules

Short and simple — this is a game we all share.

🛡️ The bot protects the game

Buttons that aren't on the list won't do anything, and the bot looks at the screen before every single press — skipping the ones that would cause problems, and unplugging itself entirely if the game ever ends up somewhere it really shouldn't be. You can't break anything by accident, so relax and have fun.

⚠️ Trying to cause trouble has consequences

Everything sent to the bot is logged, and the mods can see all of it. Deliberately trying to mess up the game, the save, or the stream will get commands ignored — and can mean a timeout or a ban. Don't be that person; it's never worth it.
